QuackQuery is a small analytics assistant. Give it a CSV file — or pick one of the bundled demo datasets — type a question like “which city has the highest total funding?”, and it writes the SQL, shows you exactly what it wrote, runs it, and answers in plain English with a chart. No SQL knowledge needed.

How it works

1Pick your data

Load a demo dataset or upload your own CSV. Your file is profiled once — column types, sample values, descriptions — and nothing leaves the server’s embedded DuckDB database.

2Ask in English

Type any analytical question. The question, the column catalog and a few rules go to Gemini, which writes a single read-only SQL query.

3See everything

The exact SQL, the result rows, a chart and a plain-English answer — streamed live, stage by stage. If the SQL fails, you watch it repair itself.

Why trust it

The SQL is always shown

Every answer ships with the exact query that produced it. Audit the logic, not vibes — copy the SQL into your own tool and re-run it if you like.

Dangerous SQL is blocked

A deny-by-default guard rejects anything that isn’t a single read-only SELECT — stacked statements, PRAGMA, file-read functions and friends never reach the database.

Wrong SQL self-repairs

When a query fails, the error is fed back for up to 3 repair passes — and you see every attempt in the pipeline view, including the ones that failed.

See it answer a real question

Three demo datasets are bundled — IPL matches, e-commerce orders, and Indian startup funding. One click loads them; one more asks your first question.
