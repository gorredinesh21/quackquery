QUACKQUERY

Ask your CSV questions in plain English

QuackQuery turns your question into SQL, shows you the query for full auditability, runs it, and answers in plain English — with a chart. If the SQL fails, it self-corrects up to 3 times, and you see every attempt.

Why trust it

The SQL is always shownEvery answer ships with the exact query that produced it. Audit the logic, not vibes.
Dangerous SQL is blockedA deny-by-default guard rejects stacked queries, PRAGMA, and file-read functions (read_csv, ATTACH, …) before anything runs — DuckDB itself is read-only on top.
Wrong SQL self-repairsWhen a query fails, the error is fed back for up to 3 repair passes — and you watch every attempt in the pipeline.
